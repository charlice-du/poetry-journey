# Poetry Journey (詩中行)

Browser-based interactive narrative game exploring classical Chinese poetry through interactive storytelling.

**Tencent “AI CAN DO IT” Global AI Game Development Hackathon — Global Finals 2nd Prize, 2026**

[Play Online](https://poetryjourney.online)

## Overview

Poetry Journey was developed by a three-person HKU team for the Tencent
“AI CAN DO IT” competition.

The game combines classical Chinese poetry, interactive narrative,
stylized visual presentation, and AI-assisted experiences.
