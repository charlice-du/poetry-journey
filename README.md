# Poetry Journey (詩中行)

Browser-based interactive narrative game exploring classical Chinese poetry through interactive storytelling.

**Tencent “AI CAN DO IT” Global AI Game Development Hackathon — Global Finals 2nd Prize, 2026**

[Play Online](https://poetryjourney.online)

## Overview

Poetry Journey was developed by a three-person HKU team for the Tencent
“AI CAN DO IT” competition.

The game combines classical Chinese poetry, interactive narrative,
stylized visual presentation, and AI-assisted experiences.

## My Contributions

- Created the visual assets used in the preliminary round with generative image tools.
- For the Global Finals, researched and structured content/data for the team's Creative Workbench and helped establish its initial knowledge base.
- Contributed to the initial prototype and functionality of the Creative Workbench; additional features were later extended by the team lead.
- Participated in iterative testing, presentation preparation, and the final on-site showcase as part of the three-person team.
