# Public assets

No teammate image, audio, font or generated-media bundle is copied into this
folder. The project showcase currently uses images that were already hosted
and referenced by the original public README.

Before adding a new asset, record:

- creator or generating service;
- contributor permission;
- source URL or local provenance;
- applicable license or service terms;
- whether people, trademarks or third-party works appear;
- whether AI generation should be disclosed.

An asset without a clear publication basis should remain outside the public
repository.
